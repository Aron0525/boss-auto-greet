# bossgreet 操作手册（Windows 本机）

本手册面向从 GitHub 下载项目、第一次在自己电脑上使用的用户。所有命令都在 **PowerShell** 中执行。程序默认只读预览；只有明确运行 `run --send` 并在终端输入 `send` 才会尝试联系招聘方。

## 三步上手

1. 在源码目录创建虚拟环境并安装项目（见第 1 节）。
2. 用 `init` 在源码目录外创建本地工作目录（见第 2 节），填写筛选条件。
3. 第一次运行 `preview` 时在专用浏览器登录 BOSS；之后先用 `scan` 或 `preview` 核对岗位，确认后才使用 `run --send`。

最常用的安全搜索命令如下。它只搜索和筛选，不会打开沟通窗口、发送消息或写入投递记录：

```powershell
Set-Location $work
& $py -m bossgreet scan --query "AI agent" --pages 3 --show-window
```

## 1. 下载并安装

在 GitHub 页面选择 **Code → Download ZIP**，解压后用 PowerShell 进入包含 `pyproject.toml` 的目录。也可以克隆公开版仓库。以下命令从该目录开始：

```powershell
$repo = (Get-Location).Path
py -3 -m venv .venv
$py = (Resolve-Path .\.venv\Scripts\python.exe).Path
& $py -m pip install -e .
& $py -m bossgreet --help
```

如果 `py` 不存在，先安装 Python 3.10 或更新版本，再用实际 Python 程序的完整路径执行 `-m venv .venv`。最后一条命令应显示 `init`、`info`、`preview`、`scan`、`capture`、`run` 和 `export`。

## 2. 建立本地工作目录

工作目录放在源码目录外。个人配置、浏览器资料、投递记录和采集文件都留在你的电脑上。

```powershell
$work = Join-Path $env:LOCALAPPDATA 'bossgreet\work'
& $py -m bossgreet init --dir $work
notepad (Join-Path $work 'config.yaml')
notepad (Join-Path $work 'profile.yaml')
```

`init` 不覆盖已有文件。`profile.yaml` 默认是空白档案；仅填写真实且愿意发送的信息。只用平台默认招呼语时，可以保持档案空白。

## 3. 配置浏览器与筛选条件

在本地 `config.yaml` 的 `browser` 部分选择浏览器。下例使用 Edge；使用 Chrome 时将 `name` 改为 `chrome`：

```yaml
browser:
  name: "edge"                 # edge 或 chrome
  auto_start: true             # 端口未启动时自动打开所选浏览器
  executable: ""              # 找不到浏览器时填写本机 exe 完整路径
  user_data_dir: ""           # 留空则使用本机专用浏览器资料目录
  cdp_url: "http://127.0.0.1:9222"
  input_mode: "cdp"
  park_window: false           # 初次使用建议保持窗口可见
```

不要把日常浏览器的用户资料目录填入 `user_data_dir`。专用浏览器首次打开时需要你手动登录 BOSS；程序不会读取或保存密码。若端口已被另一种浏览器占用，程序会停止并提示你核对配置。

接着把示例中的 `search_queries`、`keywords`、`filter.city`、`filter.cities` 改为自己的目标，并检查 `exclude_keywords` 等过滤条件。第一次真实运行建议把 `pace.batch_size` 设为 `1`，把 `pace.daily_limit` 设为一个较小的正整数。示例配置只用于说明格式，不代表你的求职目标。

## 4. 首次登录与只读预览

配置完成后切换到本地工作目录：

```powershell
Set-Location $work
& $py -m bossgreet info
& $py -m bossgreet preview --limit 5 --pages 1 --show-window
```

`info` 只显示配置摘要，不连接浏览器。第一次 `preview` 会按 `browser.name` 启动专用浏览器并停在 **BOSS 登录页**，随后安全退出；请在弹出的专用窗口手动登录，再执行同一条预览命令。第二次执行时才会自动打开职位页。预览会导航页面、筛选岗位并读取详情，但**不会点击「立即沟通」或发送消息**。`--show-window` 方便你观察页面；窗口不要最小化。

完全不使用 AI 时，保持下面两项即可；这是公开版默认配置：

```yaml
message:
  generator: "template"
outreach:
  send_custom_message: false
```

基础安装不会安装 LLM 的 `requests` 可选依赖。此配置下，程序只使用本地筛选规则和平台账号中已有的默认招呼语。

核对输出中的岗位、公司、城市、过滤原因和预计消息。只查看列表筛选结果时可运行：

```powershell
& $py -m bossgreet scan --pages 1
```

`--query` 可以临时覆盖 `config.yaml` 中的 `search_queries`，适合搜索一个明确主题；例如：

```powershell
& $py -m bossgreet scan --query "AI agent" --pages 3 --show-window
& $py -m bossgreet preview --query "AI agent" --limit 5 --pages 1 --show-window
```

如果搜索主题与示例模板不同，记得同时调整 `keywords`、`must_keywords`、`entry_keywords` 和排除规则；否则岗位可能会被旧规则过滤掉。城市可在 `filter.city` 中填写单个城市、逗号分隔城市，或城市组（如 `珠三角`）。

## 5. 真实运行（可选）

先在 BOSS 账号中检查默认招呼语，并完成第 4 步预览。若只发送平台默认招呼语，首次建议限制为一条：

```powershell
& $py -m bossgreet run --send --greet-only --limit 1 --pages 1 --show-window
```

程序会要求输入 `send` 才开始第一批；其他输入或无交互输入会取消。后续每达到 `pace.batch_size` 条会再次暂停等待确认。真实运行时，`pace.daily_limit` 与 `--limit` 的较小值是**成功发送招呼语的上限**，不是仅扫描到的岗位数。已联系岗位记录在工作目录的 `contacted.json`，下次运行会跳过；`filter.max_per_company` 也会计入既有成功记录，避免重启后再次联系同一公司。

`--custom` 会在平台默认招呼语之后**再发送一条**自定义消息。只有在 `profile.yaml` 和话术都填写真实、且已用 `preview --custom` 核对实际文本后才使用：

```powershell
& $py -m bossgreet preview --custom --limit 1 --pages 1 --show-window
& $py -m bossgreet run --send --custom --limit 1 --pages 1 --show-window
```

发送结果不确定、记录文件损坏、消息质检告警或平台限制出现时，程序会停止。先在浏览器聊天页核对，再处理本地记录；不要直接删除 `contacted.json`，否则可能重复联系。

## 6. 本地文件与辅助命令

| 文件或命令 | 用途 |
| --- | --- |
| `config.yaml`, `profile.yaml` | 本地配置和个人档案。 |
| `contacted.json` | 已联系岗位与消息记录，用于去重。 |
| `bossgreet capture --pages 1` | 将命中的岗位和 JD 写入本地 `jobs.jsonl`，不发送。 |
| `bossgreet export --out-md 投递清单.md` | 从本地记录生成 Markdown 清单，不连接浏览器。 |
| `--shots <目录>` | 可选：将页面截图写到指定的本地目录。 |
| `Ctrl+C` | 停止当前程序；专用浏览器会继续打开。 |

如需环境诊断，在本地工作目录运行：

```powershell
& $py (Join-Path $repo 'scripts\doctor.py')
```

## 7. 常见故障

| 现象 | 处理 |
| --- | --- |
| 找不到 `config.yaml` 或 `profile.yaml` | 确认当前目录是 `$work`，或重新运行 `init --dir $work`。 |
| 找不到 Edge/Chrome 程序 | 检查 `browser.name`；在 `browser.executable` 填入本机 exe 完整路径。 |
| CDP 端口被另一种浏览器占用 | 关闭占用端口的进程，或为专用浏览器改用另一个本机端口。 |
| 浏览器已打开但预览提示未登录 | 首次预览停在 BOSS 登录页是正常行为；在**专用浏览器窗口**完成登录后，重新运行同一条预览命令。 |
| 页面提示安全校验 | 在专用浏览器窗口手动完成校验并回到职位页，再重新预览。 |
| 页面提示“工作经历不匹配” | 这是 BOSS 对该岗位的拦截。程序会跳过且不发送；不要试图绕过，改筛选经验年限或选择其他岗位。 |
| 找不到 BOSS 职位页 | 先确认已在专用浏览器完成登录，再重新运行 `preview`；它会自动打开职位页。仅在排障时才手动打开 `https://www.zhipin.com/web/geek/jobs`。 |
| 页面点击无效 | 不要最小化窗口；运行诊断工具，检查网站页面是否改版或出现安全校验。 |
| `run` 被拒绝 | 必须显式加 `--send`，并在终端输入 `send`。 |
| 去重文件损坏 | 先备份并修复本地 `contacted.json`；程序不会把损坏记录当作空记录继续发送。 |

## 8. 隐私与更新

不要把本地工作目录、浏览器资料目录、截图、日志、投递清单或含密钥的环境变量内容上传到 GitHub。`.gitignore` 只能阻止新文件误提交，无法清除已经进入 Git 历史的内容。项目升级时在源码目录更新代码并重新执行 `& $py -m pip install -e .`；放在 `$work` 的本地配置和记录不需要复制进仓库。

自动化依赖 BOSS 当前页面结构。修改页面或登录流程后，先运行只读预览核对，再决定是否真实运行。
